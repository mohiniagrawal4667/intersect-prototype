# 🧭 INTERSECT
### Making job-readiness visible — before the interview

Most hiring decisions fail before the interview even begins.
Not because of lack of talent, but because readiness is invisible.

Intersect exists to make readiness clear, measurable, and honest.

## What is Intersect?
Intersect is a tool that helps students understand how ready they are for a specific job and helps recruiters see alignment beyond keywords.
Instead of guessing whether a resume “fits” a role, Intersect shows:
- How much a resume matches
- Which skills already align
- Which skills are missing

In short, it turns resumes into clear, measurable readiness.

## Problem Statement
Today:
- Students apply without knowing if they are actually ready
- Recruiters screen resumes without seeing real skill gaps

This leads to:
- Unnecessary rejections
- Wasted effort on both sides
- Confusion about what to improve next

There is no simple way to see alignment between a resume and job requirements.

## Our Solution
Intersect bridges this gap by:
- Reading a resume (PDF)
- Extracting relevant skills
- Comparing them with required skills
- Generating a readiness score
- Clearly listing matched and missing skills

The output is transparent, honest, and actionable.

## How It Works
- Resume PDF is converted to plain text
- Text is scanned for commonly required skills
- Each matched skill contributes to the score
- Missing skills are highlighted

There is no black-box decision making. Everything can be understood by the user.

## Sample Output
INTERSECT SCORE: 52%

Matched skills:
- Python
- Machine Learning
- AWS
- Git

Missing skills:
- SQL
- Docker
- React

This helps candidates immediately know where they stand and what to work on next.

## Why This Matters
- Avoids vague or misleading feedback
- Respects the user’s ability to understand growth
- Focuses on readiness, not rejection

Intersect does not promise selection.
It shows the current reality.

## Technology Stack (Current Prototype)
- Python
- PDF text extraction
- Rule-based skill matching

This baseline is intentional to ensure clarity, fairness, and explainability.

## AI Usage
The current version uses a rule-based baseline.
Future versions can include:
- Skill weighting using ML
- Job-specific scoring
- Feedback-driven improvements

Starting simple builds trust before complexity.

## Intended Users
- Students and freshers
- Job seekers unsure of readiness
- Recruiters seeking clearer screening
- Institutions guiding skill development
